# Chuzosho Website Project Tracking

This folder is the working source of truth for Chuzosho website planning, ownership, design references, reviews, and daily handover.

## Files

- `Chuzosho-Website-Tracking.xlsx` — editable workbook used for page, section, ownership, asset, issue, and mobile-review tracking.
- `OWNERSHIP.md` — current owner map and assignment rules.
- `DAILY-UPDATES.md` — concise daily handover log.
- `THEME-REFERENCES.md` — approved visual system, references, and implementation constraints.
- `CONTENT-GOVERNANCE.md` — rules for product claims, legal copy, and content approval.

## Update routine

1. Update the workbook before the daily handover.
2. Record only requested changes or verified defects.
3. Add a named owner before work starts.
4. Mark desktop and mobile review separately.
5. Record unresolved content, form, hosting, and legal dependencies as blockers rather than guessing.
