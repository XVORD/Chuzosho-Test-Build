# Theme and Design References

## Brand thesis

Chuzosho is a modern product foundry: industrial precision, editorial restraint, and visible evidence of craft. It should feel related to HOSHŌ DIGITAL without looking like a duplicate website.

## Core palette

- Foundry black: `#0D0C0A`
- Warm paper: `#F3EEE4`
- Bright paper: `#FCF8F0`
- Signal red: `#D43B32`
- Oxide red: `#8A2D27`
- Brass: `#B08A5A`
- Muted ink: `#686158`

## Type

- Primary: Inter with Helvetica Neue and Arial fallbacks.
- Technical labels: IBM Plex Mono with Courier New fallback.
- Use one heading weight and one body weight per view.
- Do not use decorative numbering such as 01, 02, 03, or 04.

## Layout rules

- Every marketing-page hero is full viewport height and contains only the main heading.
- Contact has no hero section; it opens directly into the form experience.
- Each page needs its own composition and rhythm, while using the same tokens, header, and footer.
- Section images align to the layout grid; no accidental tilted or floating media.
- Use dividers and whitespace before card grids.
- Mobile layouts collapse deliberately rather than shrinking desktop columns.

## Reference sources

- HOSHŌ DIGITAL for navigation clarity, page discipline, and shared legal structure.
- The supplied Chuzosho presentation for foundry metaphor, palette, and industrial imagery.
- Existing Chuzosho generated image library for production visuals.
