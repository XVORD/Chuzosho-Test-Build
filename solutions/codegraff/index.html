The role

A repository is more than a pile of files. Its useful structure lives in the relationships between them.

Selection before volume

Find the right evidence first.

Useful context should be selected, not simply expanded. Whole files remain a fallback when the more focused path is not enough.

Product direction

Navigate context with intent.

The current concept is grounded in the deck’s evidence-first philosophy. Detailed commercial scope should be confirmed with the product owner.

MAP

See relationships.

SELECT

Retrieve what matters.

Prioritise evidence relevant to the question or task.

TRACE

Follow the decision.

Context discipline

Whole files are fallback.

Start narrow, follow relationships and expand only when the evidence requires it.
